# Mid Lang

Currently there is no full language speficication available

## Standard Types
- byte              : 8bit unsigned integer
- bool              : 8bit unsigned integer alias to byte
- i32               : 32bit signed integer
- u32               : 32bit unsigned integer
- f32               : 32bit single precision floating point
- usize             : word size unsigned integer

## Qualified Types
- pointer*          : a word sized address
- array[]           : holds the address to the start of the buffer and
                      the length / amount of elements in the buffer
